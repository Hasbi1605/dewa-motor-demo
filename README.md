# Dewa Motor — Front-End Demo (Static)

An interactive front-end demo of the **Dewa Motor** used-motorcycle showroom
catalog & CMS (originally Laravel), built for portfolio purposes. All data is
dummy data stored locally in the visitor's browser (localStorage) — search,
filters, create, edit, delete, and status changes work entirely on the client.

- Live demo: https://portofolio-hasbi.web.id/dewa-motor-demo/
- Original application (Laravel): https://github.com/Hasbi1605/Database_DewaMotor_CMS

Views: showroom catalog (search + category/status filters) and an admin panel
(unit CRUD with cost price, sell price, and margin — mirroring the original
`kendaraans` schema), plus stock-value statistics.

Files in `docs/` (GitHub Pages source): `index.html`, `style.css`, `app.js`.
