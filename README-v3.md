# Dewa Motor — Static Demo (Original UI)

A static mirror of the **Dewa Motor** used-motorcycle showroom & CMS (Laravel),
rendered from the original application itself — same Blade views, same styling
and assets, and the app's own seeded data — so the demo looks and navigates
exactly like the real thing. It includes the public storefront (catalog +
detail) and the admin panel (dashboard, kendaraan, kategori, dokumen) with
their create/edit forms. Forms that would need the server are intercepted
with a demo notice.

Note: the vehicle photo files themselves were never committed to the source
repository, so the unit photos shown here are stock photos of the same
make/model/year sourced from the web; document-template slots still show a
placeholder. Everything else is the app's real output.

- Live demo: https://portofolio-hasbi.web.id/dewa-motor-demo/
- Original application: https://github.com/Hasbi1605/Database_DewaMotor_CMS
